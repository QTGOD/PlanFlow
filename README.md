# PlanFlow · 个人计划管理

> 纯前端单文件 · 零依赖 · 数据完全本地化的个人计划管理工具

把任务、习惯、长期目标和 AI 规划助手整合在一个页面里：说一句话，AI 直接生成可一键添加的计划卡片。

## ✨ 核心特性

- **单文件运行** — 只有一个 `index.html`，双击即用，无需构建、无需服务器
- **数据本地化** — 所有数据存于浏览器 IndexedDB，不上传任何服务器
- **AI 深度集成** — DeepSeek / OpenAI 兼容 API，自然语言直接生成任务与计划
- **沉浸式 UI** — 玻璃拟态设计、深色/浅色主题、时段氛围背景、可折叠侧栏

## 🗂 功能一览

### 📅 今日计划
- **⚠️ 逾期任务栏** — 过期未完成的任务自动归入，红色警示置顶
- **待完成任务** — 今日到期 + 无日期任务，一键勾选完成
- 侧边栏徽章自动统计今日 + 逾期工作量

### 📋 任务管理
- 待办池 / 今日 / 周视图多视角管理
- 优先级（高/中/低）、截止日期、时长、标签、备注
- 子任务、排序、搜索与筛选
- 计时器与耗时统计

### 🎯 长期目标
- 目标 + 里程碑拆解，进度自动计算
- **新建草稿缓存** — 弹窗误触关闭不丢内容（刷新后自动清除）
- 一键"排程到日历"，AI 建议每个里程碑的执行日期

### 🔥 习惯追踪
- 每日打卡、连续天数、28 天热力图

### 💬 AI 助手

| 能力 | 说明 |
|------|------|
| 规划对话 | 基于你的任务/习惯/目标数据给出具体建议 |
| **时间解析** | "明天下午 3 点开会 1 小时" → 自动设置日期、时刻、时长 |
| **批量计划** | "这周每天晚上健身" → 一张卡片一键添加整周任务 |
| 任务卡片 | `[TASK]` / `[TASKSET]` / `[GOAL]` 卡片，点击即入库 |
| AI 拆解 | 长期目标自动拆成可执行里程碑 |
| AI 排程 | 里程碑智能分配到日历，可手动调整 |
| 周报生成 | 本周复盘与下周建议 |
| Markdown 渲染 | 标题、列表、加粗、代码等完整排版 |

- 支持任何 OpenAI 兼容接口（DeepSeek / Kimi / OpenAI 等），Base URL 与模型可自定义
- **API Key 安全** — 掩码输入 + 显示切换 + 错误信息脱敏

## 🚀 快速开始

```bash
git clone https://github.com/QTGOD/PlanFlow.git
```

直接用浏览器打开 `index.html` 即可使用。

使用 AI 功能前，到 **设置 → AI 助手** 填入 API Key（如 DeepSeek 的 `sk-...`）：
- Base URL 留空或填 `https://api.deepseek.com/v1`
- 模型默认 `deepseek-chat`

## 🛠 技术要点

- **零依赖** — 不引入任何框架与库，图表用 Canvas 自绘
- **IndexedDB** — 任务/习惯/目标/设置/聊天记录结构化存储，支持 JSON 导入导出
- **自研组件** — 自定义日期选择器与确认弹窗（无原生控件弹出，交互体验统一）
- **时区正确** — 全部日期计算基于本地时区
